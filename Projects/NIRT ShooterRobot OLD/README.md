## Overview

NIRT ShooterRobot OLD is an earlier implementation of a robotic pan/tilt tracking system using Python, computer vision, and an Arduino-controlled actuator system.

The Python application handles camera input, face detection, target selection, tracking decisions, and communication with an Arduino over Bluetooth or serial. The Arduino controls the physical pan and tilt servos and can optionally control a shooting actuator.

This codebase is no longer the active implementation.

## Project Status

This repository is archived as the old implementation.

No major development should be based on this codebase. The upcoming NIRT ShooterRobot repository will use an entirely different codebase and architecture.

This repository exists primarily to preserve the previous implementation, its source code, documentation, and Git history.
